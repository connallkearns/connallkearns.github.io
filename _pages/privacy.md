## Analytics

Analytical data is collected through Cloudflare Web Analytics for statistical purposes about site usage and performance. 

This information includes pages visits, referring websites, approximate geographic location, browser and device information, and page-loading performance metrics.

Cloudflare Web Analytics does not use cookies, browser storage or fingerprinting to track individual visitors.

Please see [Cloudflare's RUM data collection documentation](https://developers.cloudflare.com/speed/observatory/rum-beacon/), [Cloudflare Web Analytics](https://developers.cloudflare.com/web-analytics/about/), and [Cloudflare's Privacy Policy](https://www.cloudflare.com/privacypolicy/).
